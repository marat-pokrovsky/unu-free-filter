# Smart Home Web Application

This is a simple Flask web application that provides a web interface for the Smart Home Simulation.

## How to Run

1.  **Install dependencies:**
    ```bash
    pip install Flask
    ```

2.  **Run the web application:**
    ```bash
    python webapp/app.py
    ```

3.  Open your web browser and go to `http://127.0.0.1:5000/`.

## Web Application Pages

*   **`/`**: The home page, which displays a list of rooms in the smart home.
*   **`/devices`**: Displays a list of all smart devices and their current status.
*   **`/automations`**: Shows the configured automations.
*   **`/security`**: Presents the security log.
