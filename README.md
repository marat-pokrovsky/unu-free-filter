# Smart Home Simulation

This project is a Python-based simulation of a smart home environment. It demonstrates how various smart devices can be interconnected, automated, and monitored.

## Features

- **Device Management:** Add, remove, and update various smart devices like lights, thermostats, cameras, and more.
- **Automation:** Create rules and triggers to automate device actions based on time, sensor data, or other conditions.
- **Security System:** Simulate security events, monitor sensors, and get security reports.
- **Energy Management:** Track and analyze energy consumption, calculate costs, and visualize usage patterns.
- **Configuration:** Save and load the smart home configuration from a JSON file.
- **Simulation:** Run a time-based simulation to observe the smart home's behavior over time.

## How to Run

1. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the simulation:**
   ```bash
   python main.py
   ```

## Project Structure

- `main.py`: The main entry point for the simulation.
- `devices.py`: Functions for managing smart devices.
- `automations.py`: Functions for handling automations.
- `security.py`: Functions for the security system.
- `energy.py`: Functions for energy monitoring and reporting.
- `config.py`: Functions for loading and saving the configuration.
- `smart_home_config.json`: The configuration file for the smart home.
- `requirements.txt`: A list of python dependencies for the project.
